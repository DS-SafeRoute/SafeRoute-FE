# SafeRoute Frontend

화재 대피 훈련 관리 시스템 프론트엔드

## 기술 스택

React 18 · TypeScript 5.6 · Vite 5 · vanilla-extract · TanStack Query · Zustand · React Router v7

## 시작하기

```bash
pnpm install
pnpm dev
```
